Build a full-stack e-commerce website for the clothing brand “FitsNew” with a sub-brand “FitsAgain” (vintage/thrift).
The website should look and function like a modern online shopping platform,
BUT all orders must happen through WhatsApp only.
There must be NO login, NO user accounts, and NO order history.

🏬 PROJECT OVERVIEW

Create a premium, modern, mobile-friendly clothing e-commerce website with:

FitsNew → new/fresh clothing

FitsAgain → curated vintage/thrift clothing

Users can:

✔ Browse products
✔ Filter & search
✔ View product details
✔ Add multiple items to cart
✔ Order via WhatsApp from product page
✔ Order via WhatsApp from cart

No direct payment, no internal checkout, no order tracking.

➤ When user clicks Buy on WhatsApp

Redirect to:

https://wa.me/<YOUR_NUMBER>?text=<ENCODED_PRODUCT_MESSAGE>


Message must automatically include:

Hello, I want to order this product from FitsNew:

Product: <Product Name>
Price: ₹<Price>
Size: <Selected Size>
Quantity: 1
Product ID: <ID>
Product Link: <URL>

Please confirm availability.


Encode the message correctly for the WhatsApp URL.

🔥 6️⃣ CART → WHATSAPP CHECKOUT (MULTIPLE PRODUCTS)

When user clicks Checkout on WhatsApp, open ONE WhatsApp message containing ALL products in cart.

Message Format:
Hello, I want to place an order from FitsNew:

1) <Product Name>
   Size: <Size>
   Qty: <Quantity>
   Price: ₹<Price>

2) <Next Product>
   ...

Total Items: <count>
Grand Total: ₹<total_price>

Encode automatically into WhatsApp link:

https://wa.me/<YOUR_NUMBER>?text=<ENCODED_CART_MESSAGE>
